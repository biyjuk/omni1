# OmniScan (Android)

Senior-friendly camera app. You choose what to read:

1. Drag the white box over the text (drag inside to move, drag a corner to resize, drag on an empty spot to draw a new box).
2. Tap **Check**. Only the text inside the box is read.

- Text in the box: large print, translation to 18 languages, hazard alerts
- Medicine packs: name, strength, what it is used for (common medicines), how-to-use and warning lines, expiry banner, label completeness check
- Listen (text-to-speech), text size, language and script buttons

Build: push to GitHub, open Actions, run "Build OmniScan APK", download the `OmniScan-debug-apk` artifact.
Translation needs internet once per language (model download); OCR works offline.
